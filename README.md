# 8ball
8 Ball Slack Bot

Simple script for a Slack bot that responds to /8ball with sayings from a random list. 

To run:

- Download
- Put your own tokens in .env
- Open terminal and navigate to the folder
- node index.js
- Use the bot in the workplace you've configured with the Slack API thingy
